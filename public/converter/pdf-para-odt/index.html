Pronto para converter.

Este conversor transforma PDF (.pdf) em documento ODT do LibreOffice sem enviar o arquivo a nenhum servidor: a leitura e a montagem do resultado acontecem inteiramente no seu dispositivo, com download imediato.

Como converter PDF para ODT:

  1. Abra esta página — o par PDF → ODT já vem selecionado — e adicione um arquivo .pdf.
  2. Clique em Converter.
  3. Baixe o arquivo .odt gerado. Nenhum upload acontece.

O PDF de origem é lido via pdf.js: títulos e listas são reconstruídos pelo tamanho e pela posição do texto; tabelas e formatação inline do arquivo original não são recuperadas. Para PDF para TXT, só o texto corrido.

Nenhum arquivo, nome ou conteúdo é enviado ao servidor — apenas um contador agregado de conversões concluídas.

Perguntas frequentes

A conversão de PDF para ODT envia meu arquivo para algum servidor?

Não. A conversão de PDF para ODT acontece inteiramente no seu navegador: o arquivo é lido e o resultado é montado no seu dispositivo. Só um contador agregado de conversões concluídas é registrado — nunca o arquivo, o nome ou o conteúdo.

Preciso instalar algo, criar conta ou pagar?

Não. É uma página web gratuita, sem cadastro. Depois do primeiro carregamento ela funciona offline e pode ser instalada como aplicativo (PWA), se você quiser.

Existe limite de tamanho ou de quantidade de arquivos?

Não há limite imposto pelo serviço; o limite prático é a memória do seu dispositivo. Vários arquivos .pdf podem ser convertidos de uma vez.

O que é preservado ao converter PDF para ODT?

O PDF de origem é lido via pdf.js: títulos e listas são reconstruídos pelo tamanho e pela posição do texto; tabelas e formatação inline do arquivo original não são recuperadas. Para PDF para TXT, só o texto corrido.
