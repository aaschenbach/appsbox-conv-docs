Converter PDF para Markdown

Também conhecido como pdf2md — direto no seu navegador.

Este conversor transforma PDF (.pdf) em Markdown (.md) sem enviar o arquivo a nenhum servidor: a leitura e a montagem do resultado acontecem inteiramente no seu dispositivo, com download imediato.

Como converter PDF para Markdown:

  1. Abra o conversor de documentos e adicione um arquivo .pdf;
  2. Escolha Markdown como formato de saída (já vem selecionado pelo link acima);
  3. Clique em Converter documentos e baixe o arquivo .md gerado.

O PDF de origem é lido via pdf.js: títulos e listas são reconstruídos pelo tamanho e pela posição do texto; tabelas e formatação inline do arquivo original não são recuperadas. Para PDF → TXT, só o texto corrido.

Nenhum arquivo, nome ou conteúdo é enviado ao servidor — apenas um contador agregado de conversões concluídas.
