Pronto para converter.

Este conversor transforma HTML (.html) em Markdown (.md) sem enviar o arquivo a nenhum servidor: a leitura e a montagem do resultado acontecem inteiramente no seu dispositivo, com download imediato.

Como converter HTML para Markdown:

  1. Abra esta página — o par HTML → Markdown já vem selecionado — e adicione um arquivo .html.
  2. Clique em Converter.
  3. Baixe o arquivo .md gerado. Nenhum upload acontece.

Preserva a estrutura do texto — títulos, listas, ênfases, tabelas e links — passando por um HTML intermediário comum.

Nenhum arquivo, nome ou conteúdo é enviado ao servidor — apenas um contador agregado de conversões concluídas.

Perguntas frequentes

A conversão de HTML para Markdown envia meu arquivo para algum servidor?

Não. A conversão de HTML para Markdown acontece inteiramente no seu navegador: o arquivo é lido e o resultado é montado no seu dispositivo. Só um contador agregado de conversões concluídas é registrado — nunca o arquivo, o nome ou o conteúdo.

Preciso instalar algo, criar conta ou pagar?

Não. É uma página web gratuita, sem cadastro. Depois do primeiro carregamento ela funciona offline e pode ser instalada como aplicativo (PWA), se você quiser.

Existe limite de tamanho ou de quantidade de arquivos?

Não há limite imposto pelo serviço; o limite prático é a memória do seu dispositivo. Vários arquivos .html podem ser convertidos de uma vez.

O que é preservado ao converter HTML para Markdown?

Preserva a estrutura do texto — títulos, listas, ênfases, tabelas e links — passando por um HTML intermediário comum.
